DNS 与手动模式

默认 DNS 两个上游就够用，不用动。这页讲清它们分别管什么，以及什么时候该切到手动模式。

两个上游

设置默认管什么
国内上游udp://dns.alidns.com:53解析国内域名，尽量拿到国内 CDN IP
兜底上游tcp+udp://dns.google:53解析其它域名，降低污染概率

常见自定义组合：国内 udp://223.5.5.5 + 兜底 tls://1.1.1.1:853。改完记得重新「保存并热重载」。

DNS 只管「问谁解析」。哪股流量直连、哪股走代理，由路由决定 —— 两者别混着调。

高级 / 手动模式

表单底部有「高级 / 手动模式」，里面是个文本编辑器，可以直接手写 dae 的 config.dae。

  • 适合老手，或者表单覆盖不到的玩法
  • 它的保存按钮叫「保存手动配置」，跟表单的「保存并热重载」是两套动作
两种方式别混着用：上面的表单再保存一次，会重新生成配置文件，把你手写的改动整个覆盖掉。

几条使用经验

  • 改完立刻验证：保存后看顶部服务状态是否还 ON，顺手开个外站试试
  • 改配置前先去 更新 → 配置备份 卡片点「导出」，炸了能一键回退
  • 节点池空着的时候，先看服务是不是没启动 —— 订阅是启动时才拉
