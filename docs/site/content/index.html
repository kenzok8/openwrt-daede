daede

daede 是 OpenWrt 上的一体包：dae（eBPF 透明代理内核）+ daed（自带 Web 面板的发行版）+ luci-app-daede（统一 LuCI 界面）。一套 UCI 配置同时适配两个后端，切内核不用重装。

支持 OpenWrt 24.10+，推荐 25.x。装在没开 CONFIG_DEBUG_INFO_BTF 的固件上要先补 内核 BTF，否则 daed 起不来。
安装与升级 →一键脚本、签名 feed、卸载 三步上手 →选后端、填订阅、启动 内核 BTF →起不来先看这一页

两个后端不能同时运行（共用同一套 eBPF 挂载点）。切后端时 LuCI 会自动停掉另一个。

内核不是简单打包上游

做了什么结果
性能基线 + 官方 main 合并核心始终跟官方同步，同时保住连接状态合并、egress 重定向、DNS/UDP 路径这些优化

架构覆盖到 armv7（a7 / a9），靠 vmlinux-arm.h 补丁解决 trace eBPF 的编译问题。

支持范围

架构状态
x86_64 · i386完整内核包
aarch64_generic · aarch64_cortex-a53 · aarch64_cortex-a72完整内核包
arm_cortex-a7_neon-vfpv4 · arm_cortex-a9_neon完整内核包（armv7 走补丁编译）

它不是什么

  • 不是多内核面板 —— 只有 dae / daed 两个后端，同一内核的两种皮。
  • 不需要 CONFIG_DEBUG_INFO_BTF 之外的额外内核编译知识，缺 BTF 装个补丁包就行。
  • 别和 Clashoo / HomeProxy 同时抢透明代理；要共存只能切「仅内核」并错开端口。
